# 說說板 Saysay

給**暫時或長期無法說話**的人（例如氣切、高位頸髓損傷）用的大字片語溝通板。
在 iPad 的 Safari 打開就能用，不用安裝 App，也不需要會注音。

## 功能

- **大字圖卡**：點一下就唸出來，同時在上方大字顯示，方便照顧者看。
- **固定快捷鍵**：是／不是／不知道／再說一次／叫人（警示音＋全螢幕閃爍）。
- **家人錄音**：每一格都可以錄家人的聲音（可錄台語），有錄音就優先播錄音。
- **掃描模式**（照顧者陪同用）：自動一格一格亮起並唸出，病人眨眼或點頭時，照顧者按「選這個」。
- **可自訂**：格子、分類、顏色、每頁格數都能改；可匯出／匯入備份（含錄音）。
- **夜間模式**、**螢幕保持亮著**、**離線可用**（加到主畫面後）。
- 資料只存在那台平板上，不會上傳到任何地方。

## 在 iPad 上使用

1. 用 Safari 打開網址。
2. 點分享按鈕 →「加入主畫面」，之後從主畫面圖示開啟就是全螢幕，也可以離線使用。
3. **設定（⚙️）要按住一秒才會打開**，避免病人誤觸。

### 搭配 iPad 內建眼動追蹤（iPadOS 18 以上、支援的機型）

設定 → 輔助使用 → 眼動追蹤 → 開啟並完成校正。
iPad 要用支架固定在病人眼前約 30–50 公分、不能晃動。
建議在本 App 的設定把每頁格數調少（例如 3×2），格子越大越好選。

### 錄音

設定 → 進入編輯模式 → 點格子 → 「開始錄音」。第一次會詢問麥克風權限，請允許。

## 開發

純靜態網頁（HTML/CSS/JS），沒有建置步驟。

```bash
python -m http.server 8765
```

然後開 http://localhost:8765 。

線上版：https://bobe2510.github.io/para_talk/

- `data.js`：預設片語
- `app.js`：主程式
- `sw.js`：離線快取（network-first）

> 本工具只是溝通輔助，不能取代醫療團隊（語言治療師、職能治療師）的評估。
